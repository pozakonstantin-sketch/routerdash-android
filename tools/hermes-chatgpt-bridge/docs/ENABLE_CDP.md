# HOWTO: Включить CDP для браузера

## 1. Yandex (рекомендуется)

```bash
# Запустить Yandex с удалённой отладкой
open -a Yandex --args --remote-debugging-port=9222 --user-data-dir=/tmp/yandex-cdp-profile
```

После запуска откройте в браузере: `http://127.0.0.1:9222` — там будет список вкладок.

## 2. Safari

1. Откройте `С nocturnalmenus → Разработка (Develop)` (может понадобиться включить в `Настройки → Аксессуары`).
2. В меню `Разработка → Включить удалённую отладку`.
3. В `С nocturnalmenus → Разработка → Сервер удалённой отладки` выберите `Включить`.

## 3. После входа в ChatGPT

1. Запустите браузер с CDP.
2. Перейдите в `https://chatgpt.com` и войдите в аккаунт.
3. Убедитесь, что вкладка активна.
4. Запустите мост:
   ```bash
   cd tools/hermes-chatgpt-bridge
   ./scripts/run_bridge.sh
   ```

## 4. Проверка подключения

```bash
curl http://127.0.0.1:9222/json/version
```

Должен вернуться JSON с версией Chrome DevTools.

## 5. Безопасность

- **Не публикуйте порт 9222 в сеть.**
- **Не используйте `--disable-web-security`.**
- **Не копируйте профили браузера.**
- **Не устанавливайте расширения.**
